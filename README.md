## Подготовка к работе
1. Склонировать репозиторий
2. Запустить docker
```bash
docker compose up -d
```
3. Наполнить базу данных
[README.md](.dump%2FREADME.md)
4. Перейти по адресу http://localhost/ и на странице должны быть продукты.
5. На странице http://localhost/login/ можно авторизоваться.
6. Админка находится по адресу http://localhost/admin/

## Выполненные исправления безопасности

### XSS (Межсайтовый скриптинг)
- Пользовательские данные санитизируются перед сохранением в базу данных
- При обновлении пользователя разрешены только безопасные поля (name, email, phone)
- Поисковые запросы экранируются через `escapeRegExp` перед использованием в RegExp

### CSRF (Межсайтовая подделка запросов)
- Добавлен middleware `csurf` с cookie-based токенами
- CSRF-токен доступен в заголовке `X-CSRF-Token` и куки `XSRF-TOKEN`
- Все estado-изменяющие запросы защищены CSRF-валидацией

### NoSQL-инъекции
- Подключен `express-mongo-sanitize` для санитизации всех входящих запросов
- Убрана прямая вставка `req.body` в запросы к базе данных
- Параметр `status` в заказах принимается только как строка, предотвращая инъекцию через объект
- Поисковые строки экранируются перед использованием в регулярных выражениях

### Переполнение буфера
- Ограничение размера тела запроса: 10 КБ для `json` и `urlencoded`
- Ограничение размера загружаемого файла: 5 МБ в `multer`
- Валидация параметров пагинации (page, limit с минимальными и максимальными значениями)
- Ограничение длины строковых полей через Joi-валидацию

### ReDoS (Regular Expression Denial of Service)
- Исправлено регулярное выражение для телефона (`phoneRegExp`) - убраны вложенные квантификаторы
- Все поисковые запросы экранируются через `escapeRegExp` перед созданием `RegExp`

### DDoS (Distributed Denial of Service)
- Добавлен `express-rate-limit`: 100 запросов за 15 минут с одного IP
- Подключен `helmet` для установки защитных HTTP-заголовков

### Path Traversal (Обход директорий)
- Статический файловый сервер проверяет, что запрашиваемый путь находится внутри базовой директории
- Имена загружаемых файлов генерируются случайно (UUID), оригинальное имя не используется в пути
- При перемещении файлов из временной папки имя очищается от `..`

### Аудит npm-пакетов
- Проведен `npm audit`
- Критические уязвимости в `mongoose` и `proxy-addr` устранены обновлением зависимостей

### Линтинг
- Все ошибки и предупреждения ESLint исправлены
- Проект успешно компилируется TypeScript без ошибок
